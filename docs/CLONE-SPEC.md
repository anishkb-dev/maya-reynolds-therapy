# Clone spec — measured from the original

Measured at a **1456px** viewport. Total page height ≈ **7464px**.
The original is a Squarespace site on a 26-column fluid grid, so a
pixel-identical rebuild isn't the goal — matching **proportion, section
order, image placement and vertical rhythm** is.

## Typography (fluid — these are the 1456px values)

| Element | Size | Weight |
|---|---|---|
| H1 | 60.6px | **300** |
| H2 | 48.3px | **300** |
| H3 | 39.6px | **300** |
| Eyebrow / caps labels | ~12px | 600, letter-spacing ~0.16em |

Weight 300 everywhere on headings. This is the detail that separates a
good clone from an obvious one.
